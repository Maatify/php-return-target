# php-return-target

`maatify/php-return-target` is a framework-agnostic PHP library for safe internal return-target handling.

## Status

**Development / Unpublished**

The package identity and Composer foundation are established. The Runtime API has not been implemented yet, and no installable tagged version or external distribution is claimed.

## Boundary

This library is designed as a standalone, framework-agnostic Composer package. It does not own a Host application's framework, HTTP router, session, controller, authentication flow, or persistence layer.

## Requirements

- PHP `^8.4`
- Proprietary Maatify license

There is no installation command or usage example yet because the package is not published and its Runtime API is not implemented.
